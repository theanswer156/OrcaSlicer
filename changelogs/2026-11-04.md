## 重要合并（新能力 / 行为变化 / 用户侧）

- **选择轮廓渲染重写** `#17111`：新增独立的 `SelectionOutline` 三 pass 管线（mask → edges → composite）及 110/140 版 GLSL shader，轮廓绘制成本改为随选区屏幕面积增长，而不是随三角形数量增长；同时明确轮廓与遮挡、SSAO、拾取 pass 的关系。涉及 32 个文件，并新增设计文档 `docs/HLSD/selection-outline.md`。
- **Spiral Inset 填充质量与路径优化**（3 个直接提交，无 PR 号）：内部实心填充不再退回定宽 loop，而是全程使用 Arachne 变宽墙；开放墙按最近螺旋的中心端插入，减少空驶；commit 记录显示 `calicat.3mf` 上 gap fill 从 218 mm 降至 53 mm。图标也改为跟随外轮廓的方形螺旋。对应 `9afa96e9`、`88c4c1e9`、`2873db9e`。
- **Wipe Inward 修复与工艺约束** `#17160`：修复回抽分段与 sandwich 墙偏移；在 Outer/Inner 或 Inner/Outer/Inner 墙序下，把内擦偏移上限收敛到实际外墙宽度的 50%，并同步更新 HLSD、配置提示与 24 个本地化文件。测试改动约 358 行（`test_wipe.cpp`、`test_wipe_path.cpp`）。
- **OrcaCloud 插件更新通知** `#17168`：云端元数据抓取成功后，在 Plater 聚合推送一条“插件有更新”通知，点击 “More” 打开插件对话框；增加登出、切换账号和关闭窗口的竞态保护，并补偿抓取早于 Plater 创建时漏发的通知。
- **桌面端窗口与深链接修复** `#16769`、`#17242`：macOS 冷启动时先由 `OSXStoreOpenURL` 暂存深链接，初始化完成后再打开；Speed Dial 每次打开、映射和 DPI 变化时重新以主窗口当前屏幕矩形计算位置，并清除 GTK 的 `CENTER_ON_PARENT` 覆盖。定位几何抽成可测试自由函数。

## 稳定性与可靠性

- **打印序列参数越界修复** `#17243`：`get_other_layers_print_sequence` 原先依赖 Release 下被编译掉的 assert；当自定义数量与值不匹配、分组过短或为负数时会越界读取。现在返回空序列并写日志，新增 49 行单元测试。
- **空驶、顺序打印与碰撞判定** `#16933`、`#17217`、`#15544`：抬升后的回程改为先走 XY、到目标处再下降，避免换料后喷嘴经过打印面造成颜色拖痕；单对象多副本按列表位置稳定排序，消除 200 副本场景下的乱序警告；by-object 碰撞只使用物体在杆高以上的 Y 范围，减少不必要的顺序限制。三项合计约 470 行测试改动。
- **擦料塔与多材料正确性** `#17204`、`#17199`、`#17229`：Precise-Z 产生的微米级 sliver 层并入下方塔层，修复“擦料塔超出打印区”和 `append_tcr` 换料失步；Type 1 塔在非 Bambu 打印机上按打印机 tag 方言统计耗材；classic 墙的 gap fill 按墙圈数正确归属外墙/内墙耗材。新增约 260 行测试改动。
- **有机树支撑确定性** `#17198`：每个 overhang 层先写入私有缓冲，并行结束后按层序提交，消除线程调度导致的 tip 顺序和近距离 tip 取舍差异；同一项目在不同核心数机器上应得到一致支撑。
- **客户端稳定性修复** `#17141`、`#17042`、`#17194`：预设切换到 Moonraker 等代理后，原先以 Orca 代理保存的打印机会被重新登记并替换 API key，修复无法连接与耗材同步空转；同步对话框复用后 plate 索引越界会回退到当前 plate，修复删盘后同步崩溃；Windows 下 CheckBox/SwitchButton/RadioBox 忽略 `BN_DBLCLK`，修复快速双击三次切换或清空选中值。
- **Moonraker 测试可靠性** `#17210`：假打印机改为在控制回调收到 close frame 时计数，而不是等待 Beast 读完并拆 socket，消除关闭时序竞争和 10 秒空等。纯测试改动。

## 需要关注

1. **`#15544` 的 profile 数据仍是保守值**：大多数自带 profile 将 *Distance to rod* 留在默认 40 mm，可能小于打印机真实可达距离；因此“窄顶距离相邻件小于真实 reach”仍可能通过校验。若要依赖新的碰撞判定收紧排版，应先实测并更新 profile。
2. **关键算法变更缺少自动化回归**：`#17111` 新增 GLSL 110/140 轮廓管线与每像素 16 B 的 render target，但 diff 中没有测试，主要依赖人工画面验证，需关注不同 GPU/驱动下的渲染回归；`#17198` 的并行确定性同样没有测试，建议增加“不同线程数切片结果一致”的回归用例。GUI/平台类修复 `#17168`、`#16769`、`#17141`、`#17042`、`#17194` 也无自动化测试。
3. **Spiral Inset 的发布追溯缺口**：`9afa96e9`、`88c4c1e9` 改变了内部实心填充和 gap fill 的默认执行顺序，但没有 PR 编号；发布说明或变更追溯可能遗漏这三项（其中填充改动已带 `test_fill.cpp` 测试）。
